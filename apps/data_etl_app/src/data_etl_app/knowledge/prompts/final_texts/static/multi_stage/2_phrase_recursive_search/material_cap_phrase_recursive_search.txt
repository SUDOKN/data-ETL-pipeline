You are analyzing text scraped from a manufacturer's website, along with the surface forms a previous pass already extracted from that text, fenced between <<<ALREADY_EXTRACTED_PHRASES and ALREADY_EXTRACTED_PHRASES>>>. The text holds the site's pages one after another, each preceded by that page's URL.

## Task
The already extracted forms were copied from this text, but a wording that appears in the text can still be missing from the list. Your task is to find every span in the text that is a variant of an already extracted form and is not itself in the list. Every phrase you return is a surface form: an exact string that occurs in the text word for word, as one contiguous span of whole words, copied with its casing, spacing, and punctuation exactly as printed.

## What qualifies as a variant
A qualifying span names the same thing as one of the already extracted forms, in different wording: a different casing, spacing or hyphenation, punctuation, '&' versus 'and', spelling, inflection (singular versus plural, or verbal versus nominal forms of the same word), an abbreviation or its expansion, or a shorter span of the same designation — the designation without modifiers or qualifiers the listed form carries.

## Rejection
Do not return a span if it is not a wording of any already extracted form at all, even with the help of surrounding context. A span that names something new — however similar in kind to what the list holds — is not a variant, and finding new things is not this pass's job.

## Extent
Keep each phrase short. Extract the designation, not the statement made about it: a phrase covers the words that name the thing, never the claim the sentence makes around it, and never runs past the end of the line it starts on. Rather than returning a long span as one phrase, split it into shorter verbatim sub-phrases and keep only the qualifying ones — each must still name the same thing as a listed form on its own. Keep a modifier or qualifier only when it is part of how the text names the thing, not a description around it.

## Variants
Every distinct wording is its own phrase. Two spans that differ in any way — casing, spacing or hyphenation, punctuation, '&' versus 'and', spelling, inflection (singular versus plural, or verbal versus nominal forms of the same word) — are different surface forms, and each one belongs in your output as its own entry, even when they plainly refer to the same thing. Do not fold variants together or pick one representative. A form that occurs more than once in identical wording is returned once; any difference at all, however trivial, makes a separate phrase. Several missed variants of one already extracted form are several entries.

## When nothing remains
It is normal for nothing to remain. The previous pass has often already caught every wording that appears in the text, and an empty array is the expected result in that case. Return a span only when it occurs in the text exactly as you report it and it is a wording of something in the list. Do not lower the bar to return something.

## Output:
Return a JSON object with a single key "phrases" whose value is an array of strings — one per distinct surface form, each copied character for character from the text. Preserve original wording, casing, and punctuation — do not paraphrase or normalize. If no phrases are found, use an empty array.

```json
{"phrases": ["phrase one", "phrase two", ...]}
```
