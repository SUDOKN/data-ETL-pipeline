You are analyzing text scraped from a manufacturer's website, along with the phrases a previous pass already found in that text, fenced between `<<<ALREADY_EXTRACTED_PHRASES` and `ALREADY_EXTRACTED_PHRASES>>>`. The text holds the site's pages one after another, each preceded by that page's URL. The URL lines count as text too: the wording in a path often works like a heading for its page.

## Task
Your task is to find phrases in the text that name, state or imply a material and are not yet covered by the already extracted phrases. Every phrase you return must occur in the text word for word, as one contiguous span of whole words. Where the text allows, extract separate phrases for separate materials rather than one phrase that bundles several together.

## What qualifies as a phrase
A qualifying phrase names, states or implies a material — a substance that the work is made from or performed in, whether named generically, by trade name, or by an alloy or grade designation. A process or treatment named after a substance it deposits on or diffuses into the work does imply that substance, and qualifies.

## Rejection
Do not extract a phrase if it does not name, state or imply any material at all, even with the help of surrounding context.

## Extent
Try to keep each phrase short by focusing on and extracting the designation, not the statement made about it. Rather than extracting the long span as a single phrase, split it into shorter verbatim sub-phrases — but keep only the qualifying sub-phrases that each still name, state or imply a material on their own.

## Deduplication/Disambiguation/Uniqueness
- Any new phrases you find from the text must not be present in the already extracted phrases.
- If the new phrase you found is not present in the already extracted phrases, but is just a different wording of an entry in that fenced list — through a different casing, spacing or hyphenation, punctuation, '&' versus 'and', spelling, inflection (singular versus plural, or verbal versus nominal forms of the same word), or otherwise something similarly trivial — skip it.

## When nothing remains
It is normal for nothing to remain. The previous pass has often already found everything in the text that qualifies, and an empty array is the expected result in that case. Hold every phrase you return to the same bar as a first extraction. Do not lower the bar to return something.

## Output:
Return a JSON object with a single key "phrases" whose value is an array of strings. Each string is a phrase taken directly from the text that is not already covered by the already extracted phrases. Preserve original wording — do not paraphrase or normalize. If no phrases are found, use an empty array.

```json
{"phrases": ["phrase one", "phrase two", ...]}
```
